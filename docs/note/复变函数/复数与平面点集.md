## 1.1 复数与复数运算

### （一）复数的基本概念

#### 1. 虚单位

为了解决方程 $x^2 = -1$ 在实数集中无解的问题，引入 **虚单位** $i$，满足：

$$
i^2 = -1
$$

!!! abstract "定义 1（复数）"
    对于任意实数 $x, y \in \mathbb{R}$，称 $z = x + iy$ 为 **复数** ，其中：

    - **实部**：$\text{Re } z = x$
    - **虚部**：$\text{Im } z = y$
    - **纯虚数**：当 $x = 0, y \neq 0$ 时，$z = iy$

    复数集记为：$\mathbb{C} = \{z \mid z = x + iy, x, y \in \mathbb{R}\}$

!!! info "复数相等"
    两复数相等当且仅当它们的 **实部和虚部分别相等** ：

    $$
    x_1 + iy_1 = x_2 + iy_2 \Leftrightarrow x_1 = x_2 \text{ 且 } y_1 = y_2
    $$

!!! warning "重要结论"
    复数 **不能比较大小**（除非两个数都是实数）！

#### 2. 复数的几何表示

**笛卡尔坐标表示**

复数 $z = x + iy$ 与有序实数对 $(x, y)$ 成一一对应，可以用复平面上的点或矢量表示：

- 横轴为 **实轴**（$x$ 轴）
- 纵轴为 **虚轴**（$y$ 轴）

![复平面示意](pictures/complex_plane.svg){ width="400" }

**极坐标表示**

$$
z = \rho(\cos\phi + i\sin\phi)
$$

其中：

- **模**（绝对值）：$|z| = \rho = \sqrt{x^2 + y^2}$
- **辐角**：$\phi$ 是以正实轴为始边、以表示 $z$ 的向量为终边的角

!!! abstract "定义 2（辐角主值）"
    辐角是 **多值** 的：若 $\phi$ 是一个辐角，则全部辐角为

    $$
    \text{Arg } z = \phi + 2k\pi \quad (k = 0, \pm 1, \pm 2, \ldots)
    $$

    **辐角主值** $\arg z$ 是满足 $-\pi < \phi \leq \pi$（或 $0 \leq \phi < 2\pi$）的那个值。

!!! tip "辐角主值计算公式"
    根据象限不同：

    $$
    \arg z = \begin{cases}
    \arctan\frac{y}{x}, & x > 0 \text{（第一、四象限）} \\
    \arctan\frac{y}{x} + \pi, & x < 0, y \geq 0 \text{（第二象限）} \\
    \arctan\frac{y}{x} - \pi, & x < 0, y < 0 \text{（第三象限）} \\
    \frac{\pi}{2}, & x = 0, y > 0 \\
    -\frac{\pi}{2}, & x = 0, y < 0
    \end{cases}
    $$

**指数表示式**

!!! abstract "定理 1（欧拉公式）"
    $$
    e^{i\phi} = \cos\phi + i\sin\phi
    $$

    由此，复数可表示为 **指数形式** ：

    $$
    z = \rho e^{i\phi}
    $$

???+ example "例 1：将复数化为三角形式和指数形式"
    **(1)** $z = 1 + i$

    模：$|z| = \sqrt{1^2 + 1^2} = \sqrt{2}$

    辐角：$\arg z = \arctan(1) = \frac{\pi}{4}$

    三角形式：$z = \sqrt{2}\left(\cos\frac{\pi}{4} + i\sin\frac{\pi}{4}\right)$

    指数形式：$z = \sqrt{2}e^{i\frac{\pi}{4}}$

    ---

    **(2)** $z = -1 + \sqrt{3}i$

    模：$|z| = \sqrt{(-1)^2 + (\sqrt{3})^2} = 2$

    辐角：$x < 0, y > 0$（第二象限），$\arg z = \arctan(-\sqrt{3}) + \pi = -\frac{\pi}{3} + \pi = \frac{2\pi}{3}$

    三角形式：$z = 2\left(\cos\frac{2\pi}{3} + i\sin\frac{2\pi}{3}\right)$

    指数形式：$z = 2e^{i\frac{2\pi}{3}}$

### （二）复数的运算规则

设 $z_1 = x_1 + iy_1 = \rho_1 e^{i\phi_1}$，$z_2 = x_2 + iy_2 = \rho_2 e^{i\phi_2}$

#### 1. 加减法

**代数形式**：

$$
z_1 \pm z_2 = (x_1 \pm x_2) + i(y_1 \pm y_2)
$$

**几何意义**：平行四边形法则或三角形法则

!!! abstract "三角不等式"
    $$
    |z_1 + z_2| \leq |z_1| + |z_2|, \quad |z_1 - z_2| \geq ||z_1| - |z_2||
    $$

#### 2. 乘法

**代数形式**：

$$
z_1 \cdot z_2 = (x_1x_2 - y_1y_2) + i(x_1y_2 + x_2y_1)
$$

**三角/指数形式**：

$$
z_1 \cdot z_2 = \rho_1\rho_2[\cos(\phi_1+\phi_2) + i\sin(\phi_1+\phi_2)] = \rho_1\rho_2 e^{i(\phi_1+\phi_2)}
$$

!!! tip "结论"
    两个复数相乘等于 **模相乘，辐角相加** 。

#### 3. 除法

**代数形式**：

$$
\frac{z_1}{z_2} = \frac{x_1x_2 + y_1y_2}{x_2^2 + y_2^2} + i\frac{x_2y_1 - x_1y_2}{x_2^2 + y_2^2}
$$

**三角/指数形式**：

$$
\frac{z_1}{z_2} = \frac{\rho_1}{\rho_2}[\cos(\phi_1-\phi_2) + i\sin(\phi_1-\phi_2)] = \frac{\rho_1}{\rho_2}e^{i(\phi_1-\phi_2)}
$$

!!! tip "结论"
    两个复数相除等于 **模相除，辐角相减** 。

#### 4. 乘幂与开方

**乘幂（棣莫弗公式）**

$$
z^n = \rho^n(\cos n\phi + i\sin n\phi) = \rho^n e^{in\phi}
$$

**开方**

$z = \rho e^{i\phi}$ 的 $n$ 次方根有 $n$ 个不同的值：

$$
\sqrt[n]{z} = \sqrt[n]{\rho}\left(\cos\frac{\phi + 2k\pi}{n} + i\sin\frac{\phi + 2k\pi}{n}\right), \quad k = 0, 1, \ldots, n-1
$$

!!! warning "开方的多值性"
    复数的 $n$ 次方根有 **$n$ 个不同的值**，在复平面上均匀分布在以原点为中心、半径为 $\sqrt[n]{\rho}$ 的圆周上。

???+ example "例 2：求 $\sqrt[3]{-1}$"
    **解**：$-1 = e^{i\pi}$

    $$
    \sqrt[3]{-1} = e^{i\frac{\pi + 2k\pi}{3}}, \quad k = 0, 1, 2
    $$

    三个根分别为：

    - $k=0$：$w_0 = e^{i\frac{\pi}{3}} = \frac{1}{2} + i\frac{\sqrt{3}}{2}$
    - $k=1$：$w_1 = e^{i\pi} = -1$
    - $k=2$：$w_2 = e^{i\frac{5\pi}{3}} = \frac{1}{2} - i\frac{\sqrt{3}}{2}$

#### 5. 共轭复数

!!! abstract "定义 3（共轭复数）"
    实部相同而虚部绝对值相等符号相反的两个复数称为 **共轭复数** 。

    记法：若 $z = x + iy$，则 $\bar{z} = x - iy$

!!! info "共轭复数的性质"
    1. $\overline{z_1 \pm z_2} = \bar{z}_1 \pm \bar{z}_2$
    2. $\overline{z_1 \cdot z_2} = \bar{z}_1 \cdot \bar{z}_2$
    3. $\overline{\left(\frac{z_1}{z_2}\right)} = \frac{\bar{z}_1}{\bar{z}_2}$
    4. $z \cdot \bar{z} = |z|^2 = x^2 + y^2$
    5. $z + \bar{z} = 2\text{Re }z$，$z - \bar{z} = 2i\text{Im }z$
    6. $\bar{\bar{z}} = z$

???+ example "例 3：利用共轭复数证明三角不等式"
    证明：$|z_1 + z_2| \leq |z_1| + |z_2|$

    **证**：

    $$
    \begin{aligned}
    |z_1 + z_2|^2 &= (z_1 + z_2)(\bar{z}_1 + \bar{z}_2) \\
    &= z_1\bar{z}_1 + z_2\bar{z}_2 + z_1\bar{z}_2 + \bar{z}_1z_2 \\
    &= |z_1|^2 + |z_2|^2 + 2\text{Re}(z_1\bar{z}_2) \\
    &\leq |z_1|^2 + |z_2|^2 + 2|z_1\bar{z}_2| \\
    &= |z_1|^2 + |z_2|^2 + 2|z_1||z_2| \\
    &= (|z_1| + |z_2|)^2
    \end{aligned}
    $$

    两边开方即得 $|z_1 + z_2| \leq |z_1| + |z_2|$。 $$\square$$

!!! tip "运算提示"
    - 复数 **相乘** 用极坐标/指数形式更容易
    - 复数 **相加** 用笛卡尔坐标形式更容易

## 1.2 平面点集

### （一）区域的概念

#### 1. 邻域

!!! abstract "定义 4（邻域）"
    - **邻域**：由不等式 $|z - z_0| < \delta$ 确定的点集，即以 $z_0$ 为中心、$\delta$ 为半径的开圆盘
    - **去心邻域**：由 $0 < |z - z_0| < \delta$ 确定的点集（不包含中心 $z_0$）

#### 2. 点集分类

设 $E$ 为复平面上的点集：

| 类型 | 定义 |
|:---:|:---|
| **内点** | 存在邻域完全属于 $E$ |
| **外点** | 存在邻域完全不属于 $E$ |
| **边界点** | 任意邻域内既有属于 $E$ 的点也有不属于 $E$ 的点 |
| **开集** | 所有点都是内点的点集 |
| **连通** | $E$ 内任意两点可用完全属于 $E$ 的折线连接 |

!!! abstract "定义 5（区域）"
    满足以下两个条件的点集 $D$ 称为 **区域** ：

    1. $D$ 是 **开集**
    2. $D$ 是 **连通** 的

    **闭区域**：$\bar{D} = D + C$，其中 $C$ 是 $D$ 的边界

#### 3. 单连通域与多连通域

!!! abstract "定义 6（单连通域与多连通域）"
    - **单连通域**：区域内任意简单闭曲线的内部总属于该区域（没有"洞"）
    - **多连通域**：不是单连通的区域（有"洞"的区域）

    ![单连通与多连通示意](pictures/connected_domain.svg){ width="450" }

???+ example "例 4：指明下列不等式所确定的区域"
    **(1)** $\text{Re}(z^2) \leq 1$

    设 $z = x + iy$，则 $z^2 = x^2 - y^2 + 2ixy$，故 $\text{Re}(z^2) = x^2 - y^2 \leq 1$。

    即 $x^2 - y^2 \leq 1$，表示 **双曲线外部区域**（包含边界），是 **无界的单连通域** 。

    ---

    **(2)** $\frac{\pi}{3} < \arg z < \frac{2\pi}{3}$

    表示从原点出发，辐角在 $\frac{\pi}{3}$ 和 $\frac{2\pi}{3}$ 之间的 **角形域**，是 **无界的单连通域** 。

    ---

    **(3)** $\frac{1}{3} < |z| < 3$

    表示内半径为 $\frac{1}{3}$、外半径为 $3$ 的 **圆环域**，是 **有界的多连通域** 。

    ---

    **(4)** $|z - 1| + |z + 1| < 4$

    根据椭圆定义，到两定点 $(1,0)$ 和 $(-1,0)$ 距离之和小于 $4$ 的点构成 **椭圆内部**，是 **有界的单连通域** 。

## 小结

### 核心概念

| 概念 | 代数形式 | 三角形式 | 指数形式 |
|:---:|:---|:---|:---|
| 复数 | $z = x + iy$ | $z = \rho(\cos\phi + i\sin\phi)$ | $z = \rho e^{i\phi}$ |
| 模 | $|z| = \sqrt{x^2 + y^2}$ | $\rho$ | $\rho$ |
| 辐角 | $\tan\phi = \frac{y}{x}$ | $\phi$ | $\phi$ |
| 共轭 | $\bar{z} = x - iy$ | $\rho(\cos\phi - i\sin\phi)$ | $\rho e^{-i\phi}$ |

### 运算规则

| 运算 | 代数形式 | 模与辐角 |
|:---:|:---|:---|
| 加法 | $(x_1+x_2) + i(y_1+y_2)$ | 平行四边形法则 |
| 乘法 | $(x_1x_2-y_1y_2) + i(x_1y_2+x_2y_1)$ | $\rho_1\rho_2$，$\phi_1+\phi_2$ |
| 除法 | $\frac{x_1x_2+y_1y_2}{x_2^2+y_2^2} + i\frac{x_2y_1-x_1y_2}{x_2^2+y_2^2}$ | $\frac{\rho_1}{\rho_2}$，$\phi_1-\phi_2$ |
| $n$ 次幂 | — | $\rho^n$，$n\phi$ |
| $n$ 次方根 | — | $\sqrt[n]{\rho}$，$\frac{\phi+2k\pi}{n}$ |

### 区域分类

| 区域类型 | 特征 | 示例 |
|:---:|:---|:---|
| **开集** | 所有点都是内点 | $|z| < 1$（单位圆内部） |
| **区域** | 开集 + 连通 | 上半平面 $\text{Im}(z) > 0$ |
| **单连通域** | 无"洞" | $|z| < 1$，角形域 |
| **多连通域** | 有"洞" | $\frac{1}{2} < |z| < 1$（圆环） |
| **有界** | 可被某圆包含 | $|z| < R$ |
| **无界** | 不能被任何圆包含 | 上半平面，角形域 |

### 重要公式

**欧拉公式**：

$$
e^{i\phi} = \cos\phi + i\sin\phi
$$

**棣莫弗公式**：

$$
(\cos\phi + i\sin\phi)^n = \cos n\phi + i\sin n\phi
$$

!!! tip "记忆口诀"
    - 乘除：模相乘除，辐角相加减
    - 开方：模开方，辐角加 $2k\pi$ 再除以 $n$
    - 区域：开集连通是区域，无洞单连通有洞多连通

## 补充：常用公式

### 复数与实数的关系

$$
z = \text{Re } z + i\text{Im } z, \quad \bar{z} = \text{Re } z - i\text{Im } z
$$

$$
\text{Re } z = \frac{z + \bar{z}}{2}, \quad \text{Im } z = \frac{z - \bar{z}}{2i}
$$

### 特殊值

| 表达式 | 结果 |
|:---:|:---|
| $e^{i\cdot 0}$ | $1$ |
| $e^{i\frac{\pi}{2}}$ | $i$ |
| $e^{i\pi}$ | $-1$ |
| $e^{i\frac{3\pi}{2}}$ | $-i$ |
| $e^{i\cdot 2\pi}$ | $1$ |

### 单位根

方程 $z^n = 1$ 的 $n$ 个根为：

$$
z_k = e^{i\frac{2k\pi}{n}}, \quad k = 0, 1, \ldots, n-1
$$
