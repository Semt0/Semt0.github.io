• 对于无法用初等函数表示的常微分方程初值问题, 可以寻求数值解.

• 数值解的思路为, 将自变量 x 离散化成一个单调递增的序列

      x0 < x1 < · · · < xN                                                                                  (19.1)

  如果不特别说明, 一般认为这些点的间隔是均匀的, 并记作

      h = xk+1 − xk ,             ∀k = 0, 1, · · · , N − 1                                                  (19.2)

• 常微分方程初值问题的数值算法寻求一种计算格式:

      yn+1 = G(yn+1 , yn , · · · , yn−k )                                                              (19.3)

  其中
  ▷ yn 是这种计算方法下 y(xn ) 的近似值, 以及
  ▷ y(xn ) 表示的是 y = y(x) 在点 x = xn 的准确值.

  是由于误差累积导致的当前误差的大小.

  ln+1 = O(h p+1 ) , 则称该方法具有 p 阶精度.

      y ′ = λy,          λ∈C                                                                   (19.7)

  对于给定步长 h > 0, 假设计算 yn 时引入误差 ρn . 若这个误差在计算

      yn+1 = yn + hf (xn , yn ),    n = 0, 1, 2, · · · , N − 1                                  (19.11)

  其中 N 为区间 [a, b] 的离散点个数.

表示的是点 x = xn 处的准确值.

  算法 19.1 E ULER 法算法流程
   输入:                           1: y[1] = y0;
   ▶ 微分方程右端函数接口, 表示              2: h = (b-a)/(N-1);
     为 f(x,y);                   3: x = a;
                                 4: for i = 2, 3, ..., N do
   ▶ 函数区间, 分别存储于 a 与 b;          5: y[i] = y[i-1] + h * f(x, y[i-1])
   ▶ 函数初始条件 y(a) 存储于 y0;         6: x ← x + h;
     以及
                                 7: end for
   ▶ 离散点数量 N.

   输出:
   ◀ 函数结果, 存储于 y[1:N].
