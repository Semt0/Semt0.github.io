      f (x) = 0                                                                                         (18.1)

      f (x) ≈ f (x0 ) + f ′ (x0 )(x − x0 )                                                              (18.2)

   输入:                            1: k = 0;
   ▶ 非线性函数接口 f(x), 及其导            2: x0 = x;
     函数接口 fp(x);                  3: while k < N do
                                  4: x1 = x0 - f(x0)/fp(x0);
   ▶ 初始猜测值存储于 x;                  5: if |x1 - x0| < EPS then
   ▶ 最大迭代数 N; 以及                  6:       Exit
   ▶ 迭代结束阈值 eps.                  7: end if
                                  8: k ← k+1;
                                  9: x0 = x1;
   输出:                           10: end while
   ◀ f(x) 在初始猜测值附近的根             11: x = x1.
     的近似值, 存储于 x.

  (再次) 了解 IEEE 单精度标准下, 32 位浮点数的存储格式:

                 s                     E                            M

             bit 31              bit 30 · · · 23               bit 22 · · · 0

  其中第 31 位为符号位, 第 23 − 30 为指数位, 第 0 − 22 位为尾数位. 尾数 M 尽
  管用 23 个比特位表示, 但按照 IEEE 单精度标准, 它表示的是小数点后的二进
  制信息, 因此, M ∈ [0, 1). 而一个浮点小数则表示为

      x = (−1)s (1 + M )E−127                                                                           (18.65)
