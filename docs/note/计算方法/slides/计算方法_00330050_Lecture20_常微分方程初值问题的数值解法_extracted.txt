     为 f(x,y);                   3: x = a;
                                 4: for i = 2, 3, ..., N do
   ▶ 函数区间, 分别存储于 a 与 b;          5: k1 = h * f(x, y[i-1]);

                                 7: y[i] ← y[i-1] + k2;

   ▶ 离散点数量 N.                    9: end for

   输出:
   ◀ 函数结果, 存储于 y[1:N].
