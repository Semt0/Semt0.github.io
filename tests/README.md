# 回归测试与验收

以下命令在仓库根目录执行；Python 依赖使用 `uv sync --frozen` 安装，Node.js 需要 22+。完整发布流程见 [README](../README.md#检查与发布)。

## 自动检查

```bash
bash update.sh --check
uv run python -m unittest discover -s tests -p 'test_*.py'
node --experimental-vm-modules --test tests/*.test.mjs
uv run zensical build --clean
uv run python scripts/check_site.py
git diff --check
```

| 检查 | 覆盖内容 |
|---|---|
| `update.sh --check` | 时间线和导航是否与当前内容一致，不修改文件；过期时非零退出 |
| `test_site.py` | YAML 元数据、确定性排序、URL/HTML 转义、生成标记、导航分组与路径、生成文件一致性 |
| `waline.test.mjs` | 本地客户端哈希、初次挂载、异步加载期间切页、关闭评论、实例清理、路径键和下载失败后的重试 |
| `check_site.py` | 构建路由、评论容器数量、首页结构、友链评论键、时间线条目数、本地脚本和样式、五个入口页的本地链接 |

Python / Node 测试不依赖外部服务，也不依赖被忽略的 `.trae` / `.claude` 文件。Waline 测试使用模拟模块，不向线上发布评论。构建检查必须在构建完成后运行，不能用上一次残留的 `site/` 代替本次构建。

自动检查不覆盖浏览器布局、所有历史正文链接、所有图片或 PDF、图标渲染、字体 CDN、CodeTime 和线上评论后端。检查输出的页数来自当前构建，不是固定验收数量。

## 浏览器验收

修改主题、模板、交互或资源时，在本地预览中完成与改动相关的检查：

- 桌面和约 390 像素宽手机视口：主页、三个内容索引、友链和代表性文章保持同一视觉风格，整页无横向溢出。
- 自动、浅色和深色主题：导航、搜索弹窗、手机抽屉、表格、代码、提示框和评论区的文字与背景清晰可辨。
- 首页：头像下方显示 Semt0，CodeTime 图片实际加载，三个内容入口可访问，主页无评论区；浏览器图标与导航标志没有横版缩图留白。
- 文章：公式可见，长公式与宽表格局部滚动，目录定位、代码复制和折叠提示框正常。
- 页面切换：使用站内链接连续切页、返回；公式正常重渲染，评论没有重复挂载或出现在关闭评论的页面。
- 友链与文章评论：友链展示原首页讨论，文章使用各自路径；只需读取已有内容，不用提交测试留言。
- 减少动态效果：启用系统偏好后，装饰动画不妨碍阅读或导航。

## 常见失败

`Stale` 表示生成内容过期：运行 `bash update.sh` 并提交其修改。导航指向不存在的文件时，先确认是否移动或删除了文章，再清理旧配置。找不到构建资源时，核对 `zensical.toml`、模板引用和文件是否已入库。线上评论加载失败或徽章不显示，需继续检查浏览器请求，不能用本地测试通过推断远端服务正常。
